# CyberCrowd Salesforce Guide

Enablement for the CyberCrowd sales team moving from HubSpot to the Xypher Salesforce org.
Live at **https://saascend-org.github.io/xypher-cybercrowd-starter-guide/**

Edit the `build_cc_*.py` files, never `index.html`; rebuild with `python3 build_cc_page.py`.
Field names, dropdowns and pass/fail marks are read from Xypher production.
